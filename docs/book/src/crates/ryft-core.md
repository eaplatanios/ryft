# `ryft-core`

Intended home for core tracing, automatic differentiation, and JIT compilation. The crate is still
in an early stage and should not be depended on for production use yet. The most complete and
usable part today is the
[`Parameterized`](https://docs.rs/ryft-core/latest/ryft_core/parameters/trait.Parameterized.html)
API in the [`parameters`](https://docs.rs/ryft-core/latest/ryft_core/parameters/index.html) module.

- **Crate on crates.io:** [`ryft-core`](https://crates.io/crates/ryft-core)
- **API reference:** [`docs.rs/ryft-core`](https://docs.rs/ryft-core)
- **Source:** [`crates/ryft-core/`](https://github.com/eaplatanios/ryft/tree/main/crates/ryft-core)
