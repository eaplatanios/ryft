# `ryft-pjrt`

High-level Rust bindings for [PJRT](https://github.com/openxla/xla/tree/main/xla/pjrt) — plugins,
clients, buffers, executables, and extensions — with safe wrappers around the underlying C API and
explicit lifetime / ownership modeling.

- **Crate on crates.io:** [`ryft-pjrt`](https://crates.io/crates/ryft-pjrt)
- **API reference:** [`docs.rs/ryft-pjrt`](https://docs.rs/ryft-pjrt)
